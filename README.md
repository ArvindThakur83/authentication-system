# Secure Login-Based Access Control System

This is a demo project that showcases a secure login and access control system using **Node.js**, **Express.js**, **MongoDB**, and plain **HTML/CSS/JavaScript**.

## 🔧 Tech Stack

- **Backend:** Node.js, Express.js  
- **Database:** MongoDB (Local or Atlas)  
- **Frontend:** HTML, CSS, JavaScript  
- **Authentication:** Session-based (no JWT)

## ✨ Features

- 🔐 **User Authentication:** Registration and login functionality
- 🌐 **Access Control:** Public and private pages with differentiated access
- 🎨 **Simple UI:** Clean, user-friendly interface with intuitive navigation
- 🧠 **Session Handling:** Maintains user sessions without using JWT
- ✅ **MongoDB Support:** Works with both local MongoDB and MongoDB Atlas

## 🚀 Getting Started
